# Бидний дурсамжийн булан · V3

## V2-оос шинэчлэх
1. Хуучин index.html доторх `window.WALL_CONFIG={url:'...',key:'...'};` мөрийн төслийн URL болон publishable/anon key-г шинэ index.html-д хуулна.
2. GitHub дээрх index.html-г шинэ файлаар солино. Бүх материалын зураг файлын дотор багтсан тул тусдаа asset хэрэггүй.
3. V2-ийн SQL шинэчлэлээ өмнө нь ажиллуулсан бол шинэ SQL хэрэггүй. Өмнөх зураг, тэмдэглэл, чимэглэл хэвээр үлдэнэ. V1-ээс шинэчилж байгаа бол upgrade.sql-г нэг удаа ажиллуулна. Шинэ төсөл бол setup.sql дэх хоёр UUID-г өөрийн бодит Auth User ID-аар солиод ажиллуулна.
4. GitHub Pages холбоосоо нээж 0707 кодоо оруулна. Хамтын горимд Supabase-ийн хоёр зөвшөөрөгдсөн бүртгэлээр тус тус нэвтэрнэ. Тохиргооны товчийг устгасан боловч Supabase нэвтрэх цонх хэвээр. Нэрийг бүртгэлийн и-мэйлээс автоматаар авна (хуучин хадгалсан нэр хэвээр байж болно).

## V3 үйлдлүүд
- Модон хүрээ, эсгий, даавуу, үйсэн, цаас, модон гадаргууг процедурын текстурээр сайжруулсан. Самбарын өнгө хэвээр өөрчлөгдөнө.
- Тэмдэглэл засахдаа Фонт цэсийг нээж бодит жишээ бичвэрээр сонгоно. Үсгийн хэмжээ нь тэмдэглэлийн өргөнөөс тусдаа.
- Дурсамжийг сонгоод булангийн ↻ бариулыг чирж эргүүлнэ. Shift дарж чирвэл 15° алхамтай; ±1° товч болон тоон өнцгийн талбар хэвээр.
- Утас болон гэрлийн үзүүрийн дугуй бариулыг чирж нөгөө үзүүрийг ойролцоогоор хэвээр хадгалан сунгана/эргүүлнэ. Утас бүхэлд нь зөөхөд үзүүрүүд 14 дэлгэцийн пикселээс дотогш ойртвол нийлнэ. Хол зайнаас татахгүй. Энэ нь байнгын холбоос биш: дараа нь нэг утсыг зөөхөд нөгөө нь дагаж зөөгдөхгүй. Өнцгийг бүхэл градусаар хадгалдаг тул үзүүрийг тусад нь чирэхэд эсрэг үзүүр бага зэрэг шилжиж болно.
- Утасны муруй, өнгө, гэрлийн горимыг засахдаа шууд харах боломжтой.
- Эможи наалт дээр Засах товч гарахгүй, харин хэмжээ, эргэлт, байрлал, давхаргыг өөрчилж, хувилах/устгах боломжтой.
- Чимэглэл > Өөрийн эможи: гар утасны эможи гараас оруулна. Хөтөчийн тухайн үед зурсан дүрсийг 384×384 тунгалаг PNG болгон appearance JSON-д хадгална. Ингэснээр хүлээн авагч төхөөрөмжийн өөр фонт эможиг дахин зурахгүй. Дэмжигдээгүй эможи эсвэл өнгөт эможиг зөв зурахгүй хөтөч байвал Эможи зураг нэмэх сонголтоор өөрийн PNG/зураг оруулна. V2-ийн хуучин эможи наалтууд төхөөрөмжийн эможи фонтоор харагдсаар байна; ижил дүрстэй болгохын тулд дахин нэмнэ.
- Зургийн шахалт V2-той ижил: 1600px хүртэл, ойролцоогоор 150KB зорилттой, JPEG.

## Аюулгүй байдал ба хязгаарлалт
0707 бол зөвхөн front-end түгжээ. GitHub-ийн эх кодод харагдана. Бодит мэдээллийг Supabase Auth болон зөвхөн хоёр хэрэглэгчид зориулсан RLS хамгаална. Нууц/service_role key-г HTML-д хэзээ ч оруулахгүй. Зураг, хувийн мэдээлэл HTML-д битгий оруул.

Холболтын URL/key байхгүй үед IndexedDB-ийн локал горим ажиллана; хоёр төхөөрөмжид автоматаар хуваалцахгүй. Хамтын горим 8 секунд тутамд шинэчилнэ; нэг зүйлд зэрэг өөрчлөлт хийвэл сүүлчийн амжилттай хадгалалт үлдэнэ. 1000 хүртэл мөрийг ачаална. Эможи PNG нь хэмжээнээс хамаарч нэмэлт өгөгдөл шаардана. Өмнөх V2 SQL JSONB багана эможиг хадгалж чадна.

Chromium дээр орлуулсан локал хадгалалттай тестээр PIN, фонт, үсгийн хэмжээ, ±1° болон чирж эргүүлэх, ойрын snap, муруйн preview, custom emoji, материалын өөрчлөлт шалгасан. Энд бодит IndexedDB/HTTPS сервер, Supabase болон iOS/Android хос төхөөрөмжөөр туршаагүй. Бодит төхөөрөмжүүд дээр шалгана уу.
